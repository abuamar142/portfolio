## Findings

### 1. HIGH — R-02: em dash (`—`) in UI copy and prose
The em dash is a Hard Gate rule with no exception outside the rule's own documentation. It is pervasive.

| Location | Count | Evidence |
|---|---|---|
| `src/locales/en.ts` | 43 | e.g. `en.ts:22` `'…references — organized by topic…'` |
| `src/locales/id.ts` | 42 | e.g. `id.ts:22` `'…yang berguna — diorganisir per topik…'` |
| `src/components/QuoteCard.vue:13` | 1 | rendered `— {{ displayAuthor }}` |
| `src/components/QuoteModal.vue:16` | 1 | rendered `— {{ … }}` |
| `src/pages/QuoteDetailPage.vue:47` | 1 | rendered `— {{ … }}` |
| `src/components/ShareButton.vue:99` | 1 | share text `` `"${content}" — ${author}` `` |
| `content/blog/*.md` | 67 | 20 + 12 + 8 + 27 across 4 posts |

Confirmed rendered live: `curl https://abuamar.online/links` returns `…yang berguna — diorganisir…` in the meta description; `/explore` likewise.

**Reason:** R-02 forbids the em dash character in any text; use `,` `.` `:` `()` instead.
**Note:** the 67 blog-prose instances are your editorial voice. R-37 says a named pattern the owner wants to keep is their call — decide whether blog prose is in scope or only UI copy (locales + the 4 `.vue` strings).

### 2. MEDIUM — R-19: endless pulse animation on a decorative status dot
`src/components/sections/HeroSection.vue:6` renders `<span class="pulse-dot size-1.5 bg-voltage">` beside the "Open for collaboration" badge. `src/assets/main.css:866-872` gives it `animation: ping-soft 2.4s … infinite`.

**Reason:** R-19 forbids endless loops without a UX purpose; the dot marks a real state (availability), so keep the dot but drop the infinite pulse (antislop-ui "Decorative Status Dot": keep one dot, drop the glow, drop the endless pulse).

### 3. MEDIUM — R-04: Lucide icon set with no written reason
29 `.vue` files import from `lucide-vue-next` (`ArrowUpRight`, `ExternalLink`, `Github`, `Download`, `Search`, …). The glyphs are relevant to their content, but the uniform thin-stroke library look is the R-04 tell, and `DESIGN.md` documents icon *size* (`size-4`) but never *why Lucide*.

**Reason:** R-04 requires the icon set to be a deliberate choice with the relevance written down, not a default import. Either write the one-line reason in `DESIGN.md` or vary the set where a glyph is generic.

### 4. MEDIUM — R-16: filler copy "Let's build something"
`src/locales/en.ts:70` `contact: "Let's build something"` (and the id equivalent) is the exact generic filler phrase antislop-ui names as buzzword slop ("Filler Data in Fields").

**Reason:** R-16 forbids generic filler copy; replace with a specific line about what you build or what a reply gets the visitor.

### 5. LOW — R-15: generic nav label "Explore"
`src/locales/en.ts:10` `explore: 'Explore'` (id: `'Jelajahi'`) is a generic CTA-style label. It is a nav destination, not a button, so this is borderline; the real CTAs ("Contact Me", "View all", "Post Quote", "Create Snippet", "Send") are specific and pass.

**Reason:** R-15 flags "Explore" as a default CTA word; a more specific label ("Tools & writing") would say what the page holds.

### 6. LOW — R-14: uniform project cards
`src/components/sections/ProjectsSection.vue` renders every project as the same `figure-block` in a 2-col grid with identical structure (`ProjectCard.vue`). Content varies (image, tech chips), but the card shape does not.

**Reason:** R-14 asks for variation that reflects content hierarchy; if all projects are genuinely equal, write that reason down, otherwise let the flagship project take a wider treatment.

### 7. LOW — R-08: arrow on nearly every link
`ArrowUpRight` appears on project cards, footer links, mobile menu, achievements, and the hero CTA. `DESIGN.md` does document the arrow as a signature motif ("the `→` arrow slides +6px"), so this is justified, not a violation — listed only so the count is on record.

**Reason:** R-08 allows arrows with a written purpose; `DESIGN.md` supplies it. No action needed unless you want to thin them out.
